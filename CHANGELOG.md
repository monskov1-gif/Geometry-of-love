# Изменения

## [0.1.1] — 2026-10-28
### Исправлено
- Спрайты Мелоди на узких экранах (телефон) были сжаты по ширине примерно на 40%. Теперь размер ограничивается высотой или шириной сцены с сохранением пропорций и одним масштабом для всех поз. Добавлен e2e-тест пропорций для десктопа и телефона.

## [0.1.0] — 2026-10-28 — технический фундамент
### Добавлено
- Проект Vite + TypeScript в `game/`, сборка в `dist/` с относительными путями для GitHub Pages.
- Ядро новеллы: модель сценария, рантайм, условия и эффекты (флаги, отношения, качества), валидатор сценария, формат сохранений с версией.
- Интерфейс: главное меню, игровой экран, окно диалога с 7 типами текста, выборы, Auto, Skip, журнал, скрытие интерфейса, быстрое и ручное сохранение (6 слотов), автосохранение, загрузка, настройки, меню паузы, подтверждения, уведомления.
- Каркас обязательных мини-игр и интерактивных эпизодов; эпизоды `geometry-quiz` и `horizontal-walk`.
- Спрайты Мелоди: 4 позы с двух листов. Заглушки для Дамео, Сацуки, Калькулятора-Пушина, Линейки, Циркулёнка и трёх Ластиков.
- Палитры пространств (приложение, реальный мир, код) в виде токенов по брифу.
- Тесты: 30 unit-тестов (Vitest) и 5 браузерных сценариев × 2 устройства (Playwright).
- GitHub Actions: `ci.yml` (проверки PR) и `deploy.yml` (проверка, пересборка и коммит сборки в корень `main`, откуда её публикует GitHub Pages).
- Собранная игра в корне репозитория (`index.html`, `assets/`, `.nojekyll`) и команда `npm run build:pages`.
- Документация, агенты, навыки и хук для Claude Code.

### Временное (не финальное)
- **Тестовая сцена** `test-start` со служебными текстами «(тест)» — не канон.
- Тестовый набор задач `test-basics`.
- Все фоны — CSS-заглушки. Все персонажи, кроме Мелоди, — заглушки «ВРЕМЕННАЯ ЗАГЛУШКА».
- Оформление титульного экрана — оригинальная временная композиция.
