# Geometry of Love

Сюжетная визуальная новелла (психологический хоррор) с обязательными мини-играми. Работает в браузере, устанавливать ничего не нужно.

> **Статус: технический фундамент.** Готовы движок, интерфейс, сохранения, каркас мини-игр и **тестовая сцена**. Сюжетных глав пока нет. Из графики есть только 4 спрайта Мелоди. Остальные персонажи и все фоны показаны подписанными заглушками.

## Что уже работает
- Главное меню: «Новая игра», «Продолжить» (неактивна без сохранений), «Загрузить», «Настройки».
- Игровой экран: фон, спрайты, окно диалога с табличкой имени, печать текста, 7 типов текста (речь, повествование, мысль, системное, ошибка, повреждённый, воспоминание).
- Выборы с последствиями, условно недоступные варианты, сюжетные флаги, отношения, ветвления, концовки.
- Auto, Skip (только прочитанное или всё), журнал, скрытие интерфейса, быстрое сохранение и загрузка, 6 ручных слотов, автосохранение, обработка повреждённых сохранений.
- Настройки сохраняются между запусками: скорость текста, задержка Auto, режим Skip, размер текста, прозрачность окна, уменьшение движения.
- Каркас обязательных мини-игр. В нём есть тестовая геометрическая задача и интерактивный эпизод с движением только влево-вправо.
- Три палитры пространств: приложение (тетрадный лист), реальный мир, системное пространство кода.
- Управление: мышь, касание, клавиатура (Enter/Пробел — далее, L — журнал, H — скрыть, A — Auto, удерживать Ctrl — Skip, Esc — меню).

## Запуск на своём компьютере
Нужен Node.js 22 или новее.
```bash
npm ci
```
```bash
npm run dev
```
Откройте http://localhost:5173/.

## Проверки
```bash
npm run check
```
Команда запускает проверку типов, unit-тесты (включая проверку сценария на битые ссылки) и сборку.
```bash
npm run test:e2e
```
Это браузерные тесты: собранная игра отдаётся по адресу `/Geometry-of-love/`, как на GitHub Pages, и проверяется на десктопе и на мобильном.

Подробности в [docs/TESTING.md](docs/TESTING.md).

## Публикация (GitHub Pages)
Сейчас сайт публикуется старым способом: из ветки `main`, и показывает этот README. Новый процесс устроен так:
1. Изменения делаются в отдельной ветке → pull request → workflow **CI** проверяет типы, тесты, сборку и браузерные тесты.
2. После merge в `main` workflow **Deploy to GitHub Pages** ещё раз проходит все проверки и публикует игру. Если что-то упало, публикации не будет.

**Одно ручное действие (один раз):** GitHub → репозиторий → **Settings → Pages → Build and deployment → Source: «GitHub Actions»**. Пока стоит «Deploy from a branch», сайт продолжает показывать README, а шаг публикации в Deploy завершится ошибкой.

## Структура
| Папка | Что внутри |
|---|---|
| `game/` | исходный код игры (Vite + TypeScript) |
| `game/src/content/` | сцены, персонажи, фоны, переменные: всё, что пишется под сюжет |
| `tests/` | unit- и браузерные тесты |
| `docs/` | архитектура, геймдизайн, выжимка брифа, тестирование, решения |
| `materials/` | исходные материалы автора: синопсис, бриф, ТЗ, референсы |
| `.claude/` | агенты, навыки и хук для Claude Code |
| `.github/workflows/` | CI и публикация |

Куда класть новые материалы: референсы — в `materials/references/`, спрайты — в `game/src/assets/characters/<персонаж>/`. Если загружать через веб-интерфейс GitHub в корень, Claude перенесёт их сам.
