# Geometry of Love

Сюжетная визуальная новелла (психологический хоррор) с обязательными мини-играми. Работает в браузере, устанавливать ничего не нужно.

> **Статус: полная игра, версия 0.2.0.** Вся история по синопсису проходится от начала до конца: 3 тома, 15 глав, эпилог, 3 концовки, 5 сюжетных мини-игр. Диалоги написаны по синопсису и ждут правки автора (цитаты синопсиса — дословно). **Графика пока временная:** из настоящей графики есть только 4 спрайта Мелоди. Остальные персонажи — подписанные заглушки, фоны нарисованы CSS в палитрах брифа. Звука нет.

## Содержание игры
| Том | Главы | Мини-игры и эпизоды |
|---|---|---|
| I. За экраном | 1–4 | вводные уроки приложения; №1 «Выход» (платформер) |
| II. Правильный ответ | 5–9 | №2 «Правильный ответ» (задачи, 4-я нерешаемая); побег в Песочницу (влево-вправо) |
| III. За пределами экрана | 10–15, эпилог | дверь Циркулёнка (влево-вправо); №3 «Предел измерения»; №4 «Системные файлы»; №5 «Погоня» и поездка на Калькуляторе |

Концовки: № 1 «Самоучка» (глава 1, отказаться от установки), № 2 «Мой любимый ученик» (глава 9, остаться с Мелоди), № 3 «За пределами экрана» (основная линия).

## Что работает
- Главное меню: «Новая игра», «Продолжить» (неактивна без сохранений), «Загрузить», «Настройки».
- Игровой экран: фон, спрайты, окно диалога с табличкой имени, печать текста, 7 типов текста (речь, повествование, мысль, системное, ошибка, повреждённый, воспоминание).
- Выборы с последствиями, условно недоступные варианты, сюжетные флаги, отношения, ветвления, концовки.
- Auto, Skip (только прочитанное или всё), журнал, скрытие интерфейса, быстрое сохранение и загрузка, 6 ручных слотов, автосохранение, обработка повреждённых сохранений.
- Настройки сохраняются между запусками: скорость текста, задержка Auto, режим Skip, размер текста, прозрачность окна, уменьшение движения.
- Обязательные мини-игры: сюжет продолжается только после успеха, при неудаче даётся повтор. На телефоне есть кнопки управления.
- Четыре пространства с отдельными палитрами (приложение, реальный мир, мир игры, системный код) и визуальные фазы A–E из брифа.
- Сюжетные эффекты: рука из монитора, тряска, сбои, кровь, стирание персонажа, искажение Мелоди, реплики, которые программа «исправляет», имя, стёртое из всего интерфейса.
- Управление: мышь, касание, клавиатура (Enter/Пробел — далее, L — журнал, H — скрыть, A — Auto, удерживать Ctrl — Skip, Esc — меню).

## Запуск на своём компьютере
Нужен Node.js 22 или новее.
```bash
npm ci
```
```bash
npm run dev
```
Откройте http://localhost:5173/.

## Проверки
```bash
npm run check
```
Команда запускает проверку типов, unit-тесты (включая проверку сценария на битые ссылки) и сборку.
```bash
npm run test:e2e
```
Это браузерные тесты: собранная игра отдаётся по адресу `/Geometry-of-love/`, как на GitHub Pages, и проверяется на десктопе и на мобильном.

Подробности в [docs/TESTING.md](docs/TESTING.md).

## Публикация (GitHub Pages)
Игра: **https://monskov1-gif.github.io/Geometry-of-love/**

Pages настроен на «Deploy from a branch: `main` / (root)» и отдаёт собранную игру из корня `main`: `index.html` и `assets/`. Эти файлы генерируются, руками их не правят.
1. Изменения делаются в отдельной ветке → pull request → workflow **CI** проверяет типы, тесты, сборку и браузерные тесты.
2. После merge в `main` workflow **Publish build to main** снова прогоняет все проверки, пересобирает игру и, если сборка изменилась, коммитит её в корень `main`. Затем GitHub сам публикует сайт («pages build and deployment»). Если проверка упала, сборка не обновляется и на сайте остаётся прежняя версия.
3. Собрать и положить сборку в корень вручную: `npm run build:pages`.

Ручных настроек не нужно.

## Структура
| Папка | Что внутри |
|---|---|
| `game/` | исходный код игры (Vite + TypeScript) |
| `index.html`, `assets/` | собранная игра для GitHub Pages (генерируется, не редактировать) |
| `game/src/content/` | сцены, персонажи, фоны, переменные: всё, что пишется под сюжет |
| `tests/` | unit- и браузерные тесты |
| `docs/` | архитектура, геймдизайн, выжимка брифа, тестирование, решения |
| `materials/` | исходные материалы автора: синопсис, бриф, ТЗ, референсы |
| `.claude/` | агенты, навыки и хук для Claude Code |
| `.github/workflows/` | CI и публикация |

Куда класть новые материалы: референсы — в `materials/references/`, спрайты — в `game/src/assets/characters/<персонаж>/`. Если загружать через веб-интерфейс GitHub в корень, Claude перенесёт их сам.
