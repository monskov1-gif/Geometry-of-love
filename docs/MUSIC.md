# Музыка: темы и карта

Вся синтезированная музыка — оригинальные чиптюн-композиции, написанные для игры: чужого материала в них нет. Две записанные темы — собственные треки автора (Suno), они лежат в `game/src/assets/music` и звучат там, где их поставили в сценах.

## Где что лежит
| Файл | Что внутри |
|---|---|
| `game/src/audio/score.ts` | формат партитуры: секции, форма, голоса, ударные наборы, `compose()` |
| `game/src/audio/themes-world.ts` | `title`, `home-night`, `university`, `tension`, `grief` |
| `game/src/audio/themes-melody.ts` | `app-sweet`, `app-uneasy`, `game-cute`, `game-wrong`, `friends`, `code-space` |
| `game/src/audio/themes-endings.ts` | три темы концовок |
| `game/src/audio/tracks.ts` | реестр тем `TRACKS` и старые id (`TRACK_ALIASES`) |
| `game/src/audio/recorded.ts` | записанные треки и их участки |
| `game/src/audio/voice.ts` | голоса (пульс 12,5/25/50 %, треугольник, синус, пила, шум) |
| `game/src/audio/engine.ts` | воспроизведение, кроссфейды, планировщик |
| `game/src/content/music-map.ts` | какая тема где звучит |

## Карта
Тема выбирается в `musicFor()` (`content/music-map.ts`) в таком порядке:
1. **Шаг `music()` в текущей сцене**, уже пройденный, побеждает. `music(null)` — тишина. Старые общие id `'reality'`, `'app'`, `'sandbox'` означают «тема этого пространства здесь» и решаются по пунктам 2–4 (так `music('reality')` в университете играет `university`).
2. **`SCENE_MUSIC`**: строка закрепляет одну тему на всю сцену; объект задаёт тему для пространства (и, если надо, для визуальной фазы).
3. **`LOCATION_MUSIC`**: тема локации (комната Дамео, университет).
4. **`SPACE_MUSIC`**: тема пространства и фазы по умолчанию.

Музыка из предыдущей сцены не переносится: каждая глава начинается со своей темы, даже если в ней нет шага `music()`.

| Сцена | Тема | Почему |
|---|---|---|
| `ch01` | `home-night` → `university` (по локациям) → `tension` (шаг сцены) | комната, университет, ночная находка приложения |
| `ending-self-taught` | `ending-self-taught` | Концовка № 1 |
| `ch02` | (карточка: `tension` из конца гл. 1) → тишина установщика → `app-sweet` | первое знакомство с приложением |
| `ch02-day2…4` | `university` днём → `app-sweet` | те же уроки, ещё всё «мило» |
| `ch03` | `app-uneasy` под карточкой «Навсегда вместе» → `home-night` в комнате → `app-uneasy` → `game-cute` | ревность, слежка; Дамео затянуло в игру |
| `ch04` | `game-cute` → тишина у стекла → `app-uneasy` | «Выход» оказался учебным уровнем |
| `ch05` | `game-wrong` | невозможная задача, переписанные ответы |
| `ch06` | `friends` | знакомство с обитателями |
| `ch07` | `code-space` | записи прежних пользователей — холодные данные |
| `ch08` | `friends` (фаза C) → `tension` (фаза D) | план побега и предательство |
| `ch09` | `app-uneasy` | Мелоди уговаривает остаться |
| `ending-favorite-student` | `ending-favourite-student` | Концовка № 2 |
| `ch10` | `tension` | дверь Циркулёнка |
| `ch11` | `game-wrong` → `final-hush` (шаг сцены) | пропасть, гибель Линейки |
| `ch12` | `grief` (D) → `tension` (E) | исповедь после потерь, Мелоди перекрывает проходы |

Намеренно одна тема через границу глав: гл. 3 → 4 (Дамео только что попал в игру) и гл. 14 → 15 (погоня продолжается). Это записано в тесте `tests/unit/music.test.ts` (`CONTINUES`).

**Открытый вопрос для автора:** во второй фазе погони и прощании с Калькулятором (гл. 15) звучит «Corrupted Pulse», как и раньше. Если нужна своя тема «радужного следа», её можно написать и поставить в карту.

## Переходы
Смена темы — всегда кроссфейд: старая тема продолжает играть, пока затухает (~3 с), новая нарастает за 1,8 с. Запрос темы, которая уже играет, ничего не меняет — тема не перезапускается (в том числе при переходе между сценами и между алиасом и его темой). Записанные треки смешиваются на той же шине с теми же переходами; два id одного файла (`corrupted-pulse-intro` → `corrupted-pulse`) продолжают одно воспроизведение.

## Как добавить тему
1. Напиши партитуру в одном из `audio/themes-*.ts` через `compose()` (формат описан в начале `audio/score.ts`). Такт — `meter.steps` шагов (16 = 4/4, 12 = 3/4 или 12/8, 14 = 7/8); ноты `A5`, `-` — держать, `.` — пауза.
2. Зарегистрируй её в `TRACKS` (`audio/tracks.ts`) под id в kebab-case. Id сразу попадает в валидатор сценария (`content/index.ts`).
3. Поставь её в `content/music-map.ts` (сцена, локация или пространство) или шагом `music('id')` в сцене.
4. Запусти `npm run check`. Тесты проверят: тема собирается без ошибок, длится 40–90 с, у неё свой темп и своё начало, каждая тема где-то звучит, соседние главы не начинаются с одной темы.
5. Записанный трек: файл в `game/src/assets/music`, запись в `RECORDED` (`audio/recorded.ts`) с участком петли.

Новой сцене нужна запись в `SCENE_MUSIC` (тест это требует), иначе выбор темы останется на усмотрение пространства и локации.
