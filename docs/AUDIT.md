# Аудит версии 0.3 (перед масштабной переработкой)

Дата: 2026-10-29. Проверено по коду, прогону автотестов и опубликованной игре (https://monskov1-gif.github.io/Geometry-of-love/, сборка `index-B0apLBiB.js`, открыта в Chromium, ошибок в консоли нет). Предыдущий аудит (0.2.0) закрыт частично: заставка, шрифты, звук, пиксельные спрайты и одна нарисованная комната появились, остальные проблемы остались. Ниже для каждого дефекта указаны причина, необходимые изменения и способ проверки.

## Карта текущего состояния

|---|---|---|

| Локации | `render/locations/dameo-room.ts` (Canvas 2D, 384×216), остальные 19 — CSS-заглушки `styles/backgrounds.css` | одна нарисованная псевдо-3D комната; **реальной 3D-геометрии нет нигде** |

## Дефекты
| № | Дефект | Причина | Что меняем | Как проверяем |
|---|---|---|---|---|
| 1 | Локации — плоские рисунки, 19 из 20 вообще заглушки | рендерер 0.3 — Canvas 2D с проекцией «одной точки», а не 3D | Three.js + присланный `location-kit` (стены с проёмами, мебель, лампы, состояния света, блики), рендер в низком разрешении с пиксельным увеличением | скриншоты всех состояний и критики 0–10 по `critics.md`; проверка, что сцена — `THREE.Scene` с геометрией и камерой |
| 2 | Персонажи не живут в пространстве | спрайты — DOM-слой поверх фона | персонажи — billboard-объекты в 3D-сцене, стоят на полу, освещаются лампами сцены, с тенью; состояния idle / walk / turn / talk | e2e: позиция актёра на полу, смена кадров анимации |
| 3 | Спрайты не используются в мини-играх | эпизоды писались раньше генератора; `drawPlaceholder` | все эпизоды рисуют персонажей генератором (кадры ходьбы, прыжка, эмоции) | e2e-скриншоты эпизодов; поиск `drawPlaceholder` в коде должен дать 0 |
| 4 | «Предел измерения» непонятна | правило «длина от опоры до края» не показано, нет предпросмотра | новая механика с подсказкой-тенью, понятными зонами и проверяемой победой/поражением (раздел в GAME_DESIGN, помечено как решение, не канон) | unit-тесты физики + e2e: падение, повтор, победа, возврат к сюжету |
| 5 | Нет сенсорного джойстика | `createControls` делает кнопки-стрелки | круговой виртуальный джойстик + кнопки действий, pointer capture, отпускание, повторное касание, поворот экрана | e2e на мобильном профиле с touch-событиями |
| 6 | Нет кат-сцен | нет системы | Cutscene Director: шаг `cutscene` + данные (кадры, камера, движения, анимации, звук, затемнения), агент `.claude/agents/cutscene-director.md` | e2e: запуск, пропуск, загрузка сохранения после сцены |
| 7 | Сюжет в 12–15 раз короче цели | синопсис перенесён «предложение → реплика» | переписать все главы: сцены с обстоятельствами, диалоги, атмосферные эпизоды; три категории (канон / развитие / предложения) в `docs/STORY_EXPANSION.md` | счётчик объёма в тесте; обход всех путей `story-paths` |
| 8 | Музыка привязана к пространствам | `spaceTrack()` | музыкальные состояния по драматургии: шаг `music`, карта тем в `docs/MUSIC.md`, мотивы персонажей, отдельные темы концовок | unit: одна активная тема, восстановление после загрузки |
| 9 | Главы начинаются строкой в окне диалога | нет экрана | экран главы: 3D-фрагмент локации, пиксельный заголовок, музыкальный акцент; экран конца тома | e2e: экран показан, клик ведёт дальше |
| 10 | Концовка — название и абзац | нет экрана итогов | экран итогов: композиция, своя тема, последствия, судьбы персонажей, реальные решения игрока из состояния | unit: тексты итогов зависят только от реальных переменных |
| 11 | Шрифты не согласованы | Nunito в диалогах | пиксельные гарнитуры с кириллицей для всего текста (подбор и лицензия в DECISIONS) | скриншоты всех экранов, desktop + mobile |
| 12 | Skip может пропустить обязательное | — (проверить) | Skip останавливается на выборах, мини-играх и кат-сценах с обязательными событиями | e2e Skip до конца |

## Что сохраняем
Рантайм сценария, валидатор, формат сохранений (с миграциями), обязательность мини-игр, заставку, Web Audio движок, генератор пиксельных спрайтов, публикацию через `main`. Canvas-рендерер `render/locations` остаётся только как запасной вариант для мест без 3D-сцены и для мини-игр, где он уместен.

## Ресурсы
| Ресурс | Есть | Нужно |
|---|---|---|
| 3D-набор | `location-kit` автора (`materials/location-kit`, копия в `game/src/world/kit`) | локации строятся на нём |
| Спрайты Мелоди | 4 портрета (по пояс) | используются как портреты в диалоге; в 3D-сцене — пиксельная фигура генератора |
| Спрайты остальных | генератор (рабочие дизайны Дамео и Сацуки ждут утверждения автора) | — |
| Музыка | 11 синтезированных петель | полноценные композиции с развитием (A/B части, вариации мотивов), темы концовок |
| Шрифты | Tiny5, Nunito, JetBrains Mono (OFL) | пиксельный шрифт для длинного текста с кириллицей |
